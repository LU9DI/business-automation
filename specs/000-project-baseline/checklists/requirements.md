# Requirements Quality Checklist — Baseline

- [ ] Scope is bounded and independently verifiable.
- [ ] User scenarios and acceptance criteria are explicit.
- [ ] Authorization and tenant boundaries are explicit.
- [ ] Idempotency and retry behavior are explicit.
- [ ] Failure and recovery behavior is explicit.
- [ ] Security/privacy implications are covered.
- [ ] Operational/deployment verification is defined.
- [ ] Cost constraints are explicit.
- [ ] Out-of-scope items are explicit.

These are requirement-quality gates; checked items do not by themselves mean implementation is complete.
