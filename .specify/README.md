# Spec Kit

This repository follows GitHub Spec Kit / Spec-Driven Development (SDD).

Flow: constitution → specify → clarify → plan → checklist → tasks → analyze → implement → converge.

Baseline artifacts:
- `.specify/memory/constitution.md`
- `specs/000-project-baseline/spec.md`
- `specs/000-project-baseline/plan.md`
- `specs/000-project-baseline/tasks.md`

Future work must be split into bounded feature specifications under `specs/###-feature-name/`.

Official project: https://github.com/github/spec-kit
